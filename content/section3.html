Sección 3: Uso de Técnicas Analíticas Competidoras

Se implementaron 4 modelos de clasificación bajo las mismas condiciones experimentales para comparar desempeño predictivo. Objetivo: determinar si modelos más complejos superan a la Regresión Logística baseline.

🔬 Proceso de Refinamiento

El modelo de Regresión Logística presentado es el resultado de un proceso iterativo documentado en el notebook de análisis:

  1. Partimos de 35 variables originales del dataset
  2. Analizamos multicolinealidad y significancia estadística
  3. Descartamos variables redundantes (|r| > 0.7)
  4. Seleccionamos 13 variables finales (8 numéricas + 5 categóricas)
  5. Entrenamos 4 modelos para comparación robusta

Modelo de Regresión Logística Binaria (BASELINE)

El modelo de regresión logística binaria se define de la siguiente forma:

"La probabilidad de que ocurra el evento $(Y = 1)$ está dada por"

$$ P(Y = 1 \mid X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p)}} $$

Donde:

• $\beta_0$: intercepto del modelo

• $\beta_1 \ldots \beta_p$: coeficientes estimados para cada predictor $X_1 \ldots X_p$

• $X_1 \ldots X_p$: variables independientes seleccionadas

La forma logit (odds) es:

$$ \log \left(\frac{P(Y=1 \mid X)}{1 - P(Y=1 \mid X)}\right) = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p $$

Configuración Experimental

Manejo de Desbalance

Partición de Datos

Train: 1,029 muestras (70%) | Test: 441 muestras (30%) con estratificación

Validación

5-fold cross-validation aplicada en conjunto de entrenamiento

Métricas

ROC-AUC (principal), Recall, Precision, F1-Score, Accuracy
